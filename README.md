# Urban Air Quality Assistant

A single-page, dependency-free web app that helps families navigate smog: air-quality snapshot, personalised daily plan, indoor-air advice, sustainable alternatives, and a follow-up chat assistant.

## Run
No install or build step.

```bash
cd urban-air-assistant
python3 -m http.server 8000   # then open http://localhost:8000
```
(Opening `index.html` directly also works.)

## Live vs demo data
- **Live:** enter a city. The app geocodes it and reads AQI and pollutants from the free [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (no key). These are **CAMS model estimates, not ground-station readings**; source and last-updated time are shown. The hourly chart is a **model forecast**.
- **Demo:** "Try demo data", or automatic fallback when the network or API fails. Values are fabricated and labeled as such everywhere.
- **Guidance** (plan, indoor, sustainable, chat) is generated by built-in rules conditioned on the AQI and your profile. Impact notes are directional estimates, never guarantees.

## Optional GenAI backend
The chat uses rule-based, data-grounded answers by default. To use an LLM, set `CONFIG.llmEndpoint` in `index.html` to your server URL. It receives `POST {question, context:{aqi,city,demo,profile}}` and should return `{reply}`. Keep your API key on the server, and instruct the model to stay non-diagnostic and to never invent readings.

## Limitations
No ground-station or local-alert integration; city geocoding picks the top match; health guidance is general (US AQI bands) and non-diagnostic; rule-based chat covers a fixed set of topics.
